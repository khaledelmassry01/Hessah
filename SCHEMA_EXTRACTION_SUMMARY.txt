VIOLATION 1: 3NF - Transitive Dependency (stock_instruments)
  - sector_name depends on sector_code, not on id
  - Fix: Remove sector_name, JOIN with sector_reference

VIOLATION 2: 3NF - Transitive Dependency (portfolio_targets)  
  - sector_code stored redundantly when JOINable from stock_instruments
  - Fix: Remove sector_code column

VIOLATION 3: 4NF - Multi-Valued Dependencies (daily_ai_signals)
  - Multiple independent signals: smart_money_signal, market_sentiment_score
  - Fix: Decompose into signal_predictions and signal_auxiliary_metrics tables

VIOLATION 4: 5NF - Join Dependencies (model_performance_logs)
  - Monolithic table with independent metrics and hyperparameters
  - Fix: Decompose into model_metrics, model_hyperparameters, feature_importance

VIOLATION 5: Derived Data Storage (prediction_audit)
  - error_abs is calculated (ABS(predicted - actual))
  - Fix: Create VIEW for calculated fields

VIOLATION 6: Derived Data Storage (allocation_executions)
  - executed_amount_egp and residual_component_egp are calculated
  - Fix: Create VIEW for calculated fields

VIOLATION 7: Missing Foreign Keys
